### Inferences
- Coined .com names are almost all taken (only nachtra.com of 19 was unregistered). Registered does not mean in use, but the grid shows domain availability will be a modifier game (get/try/co), not a bare .com.
- Names built on the Latin vesper and noct- stems run into live class 5 supplement marks (VESPER relaxation elixirs, NOCTISLEEP, NOCTASTATIN). That is a pattern, not a coincidence: the night/sleep supplement aisle is the crowded one. Names from other languages (Nacht, notte) avoid it in the register but are less obviously "night" to English speakers.
- Quick-screened names (1-19 except the four deep-screened ones) were NOT run through per-name web search, meaning/slang or social handle checks. Those columns are reserved for the deep screens.

### Gaps
- Per-name web collision, slang and handle checks for names 2-5, 7-9, 11-17 and 19 (not done by design in the quick screen).

## Q3. Ranked top 3

### Takeaway
1. NACHTRA, 2. NOTTRA, 3. HESPERA. Nothing is clear; this ranking is by "fewest and least serious live conflicts found by these tools", with night-signal strength as the trade-off. NOCTRA is not recommended; SELENNE is a reserve that was not deep screened.

### Cited Findings
- Rank 1, NACHTRA: no mark in USPTO backend or Trademarkia; nachtra.com and all five modifier domains unregistered on 2026-10-27; no brand in web search. Weakness: pronunciation of "ch", "Nachtmahr" nightmare association, moderate night read. — see Q2 above.
- Rank 2, NOTTRA: no mark found; only nottra.com registered (2025-10-08, use unknown); no brand in web search. Weakness: weak night signal, "not-" and "nutra" sound-alike. — see Q2.
- Rank 3, HESPERA: one registered class 14 jewelry mark; hespera.com is a jewelry store, hespera.ai/gethespera.com/tryhespera.com an AI company; subtle evening meaning; calm adult feel. Weakness: every common domain taken, several HESPER- class 5/32 neighbours. — see Q2.
- Not recommended, NOCTRA: live "Noctra" launcher with "Launcher for the night shift" tagline ([getnoctra.com](https://getnoctra.com/)), $149,995 .com ([fruits.co](https://www.fruits.co/en/domain/noctra.com)), registered noctracoffee.com, pending class 11 and 21 marks.
- Eliminated, NOCTELLE: live "Nightly Sleep Cocoa" supplement site ([getnoctelle.com](https://getnoctelle.com/)).
- Reserve, SELENNE: only a dead class 34 cigar mark (97503615, abandoned 2023-11-27); selenne.com registered 2016 and parked (ww38.selenne.com redirect), other domains unregistered; the related SELENE family has 126 USPTO hits including class 5 and 43 marks; moon rather than night; the dead cigar mark gives a tobacco association. Not deep screened (no web, slang or handle checks).

### Inferences
- If the owner values an obvious night signal most, none of these three delivers it as strongly as NOCTRA or NOCTELLE; both are blocked. A Latin noct-/nox- coinage would need a form that avoids NOCTRA, NOCTA, NOCTIS and NOCTELLE, which are all taken in some live use.
- A lawyer is likely to prefer coined words with no hits (NACHTRA, NOTTRA), but those need the most brand-building because they carry little meaning.

### Gaps
- No consumer testing of how these names read; night-signal ratings are my judgment.
- Phonetic variants not searched: NAKTRA, NOCHTRA, NOTRA (searched only as notra*), HESPERRA.

### For a professional (trademark attorney)
- Full clearance on NACHTRA, NOTTRA and HESPERA, including similarity to NOCHI / NOCH ENERGY style marks, VESPER and HESPER class 5/32 marks, translation of Nacht/notte/hesperos, and common-law use.
