## Method and limits (read once)
- USPTO backend: `POST https://tmsearch.uspto.gov/prod-stage-v1-0-0/tmsearch` (undocumented endpoint behind the public search page; filings from the last days or weeks may not be loaded). I ran wildcard queries and read every returned hit (hit totals per name are in each section). Serial numbers below are the USPTO ids returned. Status text is USPTO's own.
- Trademarkia (mirror, UNVERIFIED against USPTO) was fetched with a browser User-Agent, every `?page=N` until the result count was exhausted (cap 15 pages). Rows repeat across pages, so "rows seen" can be below the stated total. Phrase queries such as "odette society" are fuzzy on Trademarkia: they return 380 to 30,000 loosely related hits (any of the words), so only the first ~150 rows were read and I used them only to look for marks containing the name; the USPTO wildcard `*name*` queries are the reliable check for phrase forms (no `<NAME> SOCIETY / CLUB / SUPPLY / TINS` mark was found for any of the six).
- Tables list every LIVE or PENDING mark (USPTO `alive`) whose wordmark contains the name stem AND that is in classes 5, 29, 30, 31, 32, 34, 35 or 43. Classes 3 and 25 are given as context only. Stem matches also catch unrelated words (e.g. NICOLETTE contains "colett", NOEL is the male name and holiday word), kept so nothing is hidden.
- Web search tool was weak on exact brand queries (returned generic caffeine-pouch pages); "no brand found" below means "not found by these tools".
- Not done: WIPO, state registers, Google result pages, Instagram / Facebook / X handles (login walls or 429 = NOT CHECKED), Sedo / Atom / Dan sale listings (only Afternic read).
- RDAP source for all domain rows: `https://rdap.verisign.com/com/v1/domain/<x>.com` (HTTP 200 = registered, 404 = not registered in .com; a 404 can still be a registry-reserved or premium name, confirm at a registrar).
